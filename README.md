# Smart Digital Business Card

A modern, responsive, and interactive digital business card built with React and Tailwind CSS.

## 🚀 Features
- 🌙 Dark/Light Mode Toggle
- 📋 One-click Email Copy with Toast Notification
- 📱 Fully Responsive Design (Mobile First)
- ⚡ Built with Vite for optimal performance

## 🛠️ Tech Stack
- React.js
- Tailwind CSS
- Vite
